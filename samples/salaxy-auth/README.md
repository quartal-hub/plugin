Salaxy Authenticated example
============================

Example of Salaxy authenticated plugin with Vercel deployment.

The sample demonstrates:

- Authentication to Salaxy IAM (https://test-iam.salaxy.com/auth/realms/salaxy)
  - Account login in https://test-iam.salaxy.com/auth/realms/salaxy/account 
- Salaxy SSO:
  - Fetching the SSO token for current account
  - Session and company info
  - Fetching list of authorized sub-accounts
  - Fetching an SSO token for sub-account
